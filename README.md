# Toot to Boot

CEEM synthesized trumpet instrument for Windows x64 VST3 hosts. Play solo trumpet or enable Trumpet ensemble for three detuned voices with stereo spread. Brilliance, Attack, Release, and Level shape the sound.

Extract the complete Toot to Boot.vst3 bundle into your VST3 folder and rescan in REAPER. Insert it on an instrument track and play MIDI or the on-screen keyboard. Supports 12-note polyphony, sustain pedal, and two-semitone pitch bend.
